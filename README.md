# Swiggy Data Analysis Project
Swiggy Data Analysis using Python/SQL

## Project Overview:
This project analyzes Swiggy food delivery data to understand customer behavior, restaurant performance, and other trends using Python.

## Objective:
To extract meaningful insights from real-world food delivery data.

##Tools Used:
- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Top restaurants analysis
- Order trends analysis
- Peak time analysis

## Key Insights:
The analysis was focused on exploring Swiggy data through various visualizations and queries.
Detailed insights are available in the Google Colab Notebook.

## Outcome:
This project provided a basic understanding of food delivery data analysis using Python and SQL.

## Conclusion:
The project demonstrates data analysis workflow including data exploration, cleaning, and visualization.
